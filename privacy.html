🔒 Transparency & Data Protection

Privacy Notice

Last Updated: October 2026

1. Overview & Tracking-Free Architecture

Welcome to raghavendragolla.com, the personal portfolio and academic website of Raghavendra Golla. This website is statically served and does not use analytics tracking cookies, advertising beacons, or behavioral user profiling.

2. Information Collected via the Contact Form

If you choose to send an inquiry through the interactive message form on the portfolio page, the following details are collected:

  • Name: To address you properly in email correspondence.
  • Email Address: To deliver a reply back to your inbox.
  • Phone Number (Optional): If provided by you for direct voice communication.
  • Topic & Message Text: The subject and content of your message.

3. Third-Party Form Transmission (Web3Forms)

Form submissions are securely transmitted via HTTPS to Web3Forms (operated by Web3Forms LLC, United States), which functions as a form-to-email transit service. Web3Forms processes the submission exclusively to forward the message directly to Raghavendra's private email inbox. Submitted data is not sold, rented, or shared with advertisers.

4. Hosting, CDN & Server Infrastructure

This website is hosted statically on GitHub Pages (GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). When your browser connects to GitHub Pages, standard technical access logs (such as your IP address, browser type, and timestamp) may be recorded by GitHub for operational security, DDOS mitigation, and content delivery purposes.

Requests are additionally proxied through Cloudflare, Inc. (101 Townsend St, San Francisco, CA 94107, USA), which provides the site's TLS termination, DNS, content delivery, and email routing. Cloudflare processes standard request metadata (IP address, user agent, requested URL and headers) to serve and protect the site. Cloudflare Web Analytics and email-address obfuscation are disabled, so no analytics or behavioural data is collected at the edge.

5. Fonts & Static Assets

All typography is self-hosted. The web font files are served directly from this site's own origin, so no request is made to any third-party font provider when you load a page. No cookies or account credentials are exchanged.

All user interface icons are embedded locally as inline SVG within the page itself. No icon fonts or third-party icon services are used.

6. Local Browser Storage & Offline Caching

To provide a fast, seamless experience across visits, this site stores non-tracking preference keys in your browser's local storage:

  • rg:theme / theme: Remembers whether you selected Light Mode or Dark Mode.
  • rg:pwa-dismissed: Remembers if you dismissed the mobile install notification, preventing recurring popups.
  • rg:push-subscribed: Remembers active web push notification status if you paired this device.

Additionally, an offline service worker (sw.js) utilises browser Cache Storage to cache static assets, stylesheets, and fonts locally on your device for instant page loads and offline reading. The cache is versioned (its name includes a release tag such as raghavendra-portfolio-v24.2) so that each new release purges the previous one. These caches contain zero personal information.

7. Career Radar Push Notifications (Opt-in)

If you connect this device to Career Radar (career.raghavendragolla.com), the W3C Push API generates a local cryptographic subscription key pair (p256dh and auth) via your browser's push service. This occurs strictly after you click "Enable Alerts" on a authenticated pairing link. You can revoke push permissions at any time directly through your browser's site settings.
